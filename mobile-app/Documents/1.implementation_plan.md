# Flutter App Optimization, Bundle Size Reduction & Asset Cleanup Plan

Analysis of the Flutter application (`moi`) identified multiple opportunities to significantly reduce bundle size, optimize app performance, clean up unused dependencies, and compress image assets.

## Summary of Findings & Savings

| Category | Optimization Item | Estimated Size Impact |
| :--- | :--- | :--- |
| **Unused Plugins** | Remove `cloud_firestore`, `firebase_analytics`, `firebase_performance`, `http`, `flutter_image_gallery_saver`, `cupertino_icons` | **Multi-MB native build & binary reduction** |
| **Unused Files & Fonts** | Remove `assets/img/image.png` (2.0 MB), `assets/img/login_bg.jpeg` (656 KB), `assets/fonts/DejaVuSans.ttf` (724 KB), `assets/fonts/ChivoMono.ttf` (121 KB), `assets/fonts/Arimo-Regular.ttf` (310 KB duplicate) | **~3.8 MB direct size reduction** |
| **Image Compression** | Compress `default-image.png`, `login_bg.webp`, `new logo.png`, `profile-men.png` | **~2.3 MB direct size reduction** |
| **Asset Config Clean up** | Clean up `pubspec.yaml` `assets:` section to eliminate redundant directory scanning and `.DS_Store` inclusions | Prevents accidental bundling of scratch files |

Total direct asset savings: **~6.1 MB (~85% asset size reduction)**.
Native binary size reduction: **Multi-MB reduction** due to stripping Cloud Firestore C++ / LevelDB / gRPC dependencies.
